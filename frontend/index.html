01 / THE MVP

Bas call.
No noise.

VINA is a small Chrome extension for private, two-person voice calls. Ek room banao, invite code bhejo, aur apne browser se connect ho jao.

BUILT FOR TWO, ON PURPOSE
01

One-to-one rooms

Host ek room banata hai; ek friend 6-character code se join karta hai.

↗
02

Live voice, browser to browser

WebRTC audio peers ke beech direct connect hota hai when the network allows it.

↗
03

Simple call controls

Apna mic mute karo, room code copy karo, ya call chhod do.

↗
04

Audio stays out of the server

Signaling room setup mein help karta hai; call audio WebRTC se travel karta hai.

02 / THE TOOLKIT

Small, useful
by design.

Everything the first version needs. Nothing pretending to be a whole social network.

A / INVITE
#

Room-code invites

Ek code privately share karo; room mein sirf do participants aa sakte hain.

B / CONTROL
MIC

Your mic, your call

Chrome mic permission, mute/unmute, connection status, and leave-call controls.

C / CONNECTION
〰

WebRTC audio

Direct peer connection when possible; encrypted media can relay through TURN when needed.

D / CONTINUITY
▣

Popup closes. Call stays.

The call engine runs in an offscreen extension document, so closing the popup doesn't intentionally end a call.

! Room codes are private invitations, not identity verification. Share them only with the person you want to call.

03 / FROM ZIP TO HELLO

Ready in
a few steps.

Load VINA in Chrome using Developer mode, create a room, and share the code with a friend.

  1. 01

    Download & extract

    Download the ZIP and extract it to a folder on your computer. Chrome cannot load a ZIP file directly.

  2. 02

    Load the extension

    Open chrome://extensions, turn on Developer mode, select Load unpacked, and choose the extracted VINA folder.

  3. 03

    Pin & start talking

    Click Chrome's puzzle-piece icon and pin VINA. Open VINA; one person selects Create room, and the other enters the code and selects Join. Both participants must allow microphone access.
